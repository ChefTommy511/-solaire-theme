# Theme Store Screenshots

Screenshots for the Shopify Theme Store listing. These need to be high-quality, well-lit, and showcase real-looking demo products (not placeholder text/images).

## Technical Requirements

- **Format:** PNG or JPEG (PNG preferred for UI clarity)
- **Resolution:** 2880×1800px (retina display at 1440px width)
- **Max file size:** 5MB per image
- **Naming convention:** Use the names below — Shopify maps these to listing positions
- **Source:** Take screenshots from a development store with realistic demo content

## Required Screenshots

### 1. Homepage — Desktop
**Filename:** `homepage-desktop.png`

Capture the full homepage showing:
- Announcement bar (if active)
- Header with logo and navigation
- Hero banner with a striking product image
- At least one content section below the hero (Featured Collection or Image with Text)
- Footer

The homepage should demonstrate the theme's full visual range — hero impact, product display, and editorial content.

## Setting Up a Demo Store for Screenshots

1. **Create a development store** in your Shopify Partners dashboard.
2. **Push the theme** with `shopify theme push --store your-dev-store.myshopify.com`.
3. **Add demo products** — sunglasses with multiple color variants, realistic prices, and high-quality photos.
4. **Create a "New Arrivals" collection** with 6–8 products.
5. **Set up navigation menus** — main menu with Home, Shop, Collections, About.
6. **Configure theme settings** — upload a logo, set social media links, customize colors.
7. **Build the homepage** in the Theme Editor:
   - Announcement Bar (e.g., "Free shipping on orders over $100")
   - Hero Banner with 2–3 slides
   - Featured Collection (New Arrivals)
   - Image with Text (brand story)
   - Testimonials (2–3 quotes)
   - Newsletter section

---

## Post-Processing

- Ensure consistent browser chrome (use Chrome or Safari, hide bookmarks bar, use a clean window).
- Crop to exactly 2880×1800px for desktop, or the appropriate mobile dimension.
- Ensure no cursor is visible in the screenshot (unless it's a hover state).
- No browser extensions, notification badges, or personal information visible.
- Color accuracy — screenshots should match the actual theme rendering.
