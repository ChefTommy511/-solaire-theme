# Solaire — Premium Sunglasses Shopify Theme

A premium Shopify Online Store 2.0 theme designed for sunglasses and eyewear brands. Built for large-format imagery, lens detail close-ups, and a luxe, fashion-forward aesthetic.

## Features
- **Mobile-first** responsive design
- **WCAG AA** accessibility compliance
- **Performance-optimized** (targeting Lighthouse 90+)
- **JSON templates** — full Online Store 2.0 support
- **Sections everywhere** — flexible page building
- **Luxe color palette** — deep charcoal, warm gold, off-white, rich black
- **Elegant typography** — serif headings, clean sans-serif body

## Color Palette
| Color | Hex | Usage |
|-------|-----|-------|
| Off-white | `#faf8f5` | Primary background |
| Warm gold | `#c9a96e` | Accent, buttons |
| Deep charcoal | `#1a1a1a` | Text, dark backgrounds |
| Rich black | `#0d0d0d` | Footer, dark sections |

## Structure
```
├── assets/         CSS, JavaScript
├── config/         Theme settings
├── layout/         Base HTML template
├── locales/        Translation strings
├── sections/       Reusable page sections
├── snippets/       Reusable Liquid components
└── templates/      JSON page templates
```

## Development
This theme is developed by **Solaire Themes** and targets the Shopify Theme Store.

### Requirements
- Shopify CLI
- Node.js 18+
- A Shopify development store

### Getting started
```bash
shopify theme init
shopify theme dev
```
